# Authored display-path graphs

All graphs in this directory are deterministic, display-only derivatives of
xiNavmeshes commit `d5de48de84868bde744e4864768a611e5aad82b0`.
Regenerate the complete catalog from repository root with:

```text
python tools/generate_all_path_graphs.py <xiNavmeshes>
python tools/validate_path_graphs.py assets/paths/*.lua
```

The production structure maps use their committed alpha layers as graph
selection masks, plus their verified seeds and elevation bands where
applicable. This keeps graph nodes on the same authored components visible in
the minimap. South Gustaberg, Port Bastok, and Metalworks are older flattened
or linework prototypes, so their graphs retain every deterministic Detour
component without connecting separate components. A destination on a different
component remains marker-only.

Kuftal Tunnel and Garlaige Citadel use separate graph artifacts for every
authored stock page. Unauthored Garlaige pages remain marker-only.
