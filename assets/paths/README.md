# Authored display-path graphs

All graphs in this directory are deterministic, display-only derivatives of
xiNavmeshes commit `d5de48de84868bde744e4864768a611e5aad82b0`.
Regenerate the complete catalog from repository root with:

```text
python tools/generate_all_path_graphs.py <xiNavmeshes>
python tools/validate_path_graphs.py assets/paths/*.lua
```

Production graphs are selected from native Detour topology with verified
seeds, elevation bands, transitions, and blocked links. They do not require a
visible structure PNG. Some retained legacy jobs use committed alpha masks as
optional diagnostic selectors; those masks are not proof of reachability and
must not require generating a new visible structure layer. A destination on an
unverified or disconnected component remains marker-only.

Kuftal Tunnel and Garlaige Citadel use separate graph artifacts for every
authored stock page. Unauthored Garlaige pages remain marker-only.
