# Wajaom Woodlands (zone 51)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both Wajaom-side points of all sixteen pinned physical handoffs, the active
Survival Guide, and five conservative nonzero initial-spawn NM records. No
structure image, transition, one-way transition, or blocked-link exception is
used.

The supported destinations occupy seventeen native components. Several
Halvung, Mamook, and Aydeewa arrival/departure points select distinct ledges or
elevation regions, and Hydra occupies another separate region. Source geometry
does not prove their drops, ramps, doors, or other traversal mechanisms, so no
cross-component link is inferred from proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration should remain authoritative through
`stock_calibration = true`; numeric scale, origin, and grid anchor remain a
live-record blocker to a fully calibrated claim.
