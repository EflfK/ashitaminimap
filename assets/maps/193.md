# Ordelle's Caves (zone 193)

## Status

This is a routing-first **partial** map. The shared graph publishes only native
Detour components containing an exact La Theine Plateau handoff, Survival
Guide, active Treasure Chest position, or active NM position. It does not
bridge floor drops, ledges, apparent overlaps, or navmesh seams. No structure
image is required or authored.

The installed stock map records and the page silhouettes assign every retained
component to pages `1`, `2`, `14`, or `15`. Completion still requires attended
captures for every one-way drop and route-affecting seam, classification of
the 104 excluded native components, and an addon reload with route, recovery,
and page-filter checks. Destinations on different retained components remain
marker-only.
