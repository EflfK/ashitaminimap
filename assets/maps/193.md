# Ordelle's Caves (zone 193)

## Status

This is a routing-first **partial** map. The shared graph publishes only native
Detour components containing an exact La Theine Plateau handoff, Survival
Guide, active Treasure Chest position, or fixed supported NM position. It does
not bridge floor drops, ledges, apparent overlaps, or navmesh seams. No
structure image is required or authored.

Completion still requires live page-membership captures for stock pages `1`,
`2`, `14`, and `15`; attended captures for every one-way drop and
route-affecting seam; classification of the 104 excluded native components;
and an addon reload with route, recovery, and page-filter checks. Until then,
destinations on different retained components are marker-only.
