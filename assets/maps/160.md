# Den of Rancor (zone 160)

## Status

This is a routing-first **partial** map. It retains native Detour components
selected by every exact zone handoff, both active Home Points, all active
Treasure Coffer possibilities, relevant NMs, and one pinned nonzero active-mob
control per otherwise unrepresented source component. It invents no links
across navmesh seams, gates, lantern mechanics, or floor changes.

The stock catalog contains pages `0` through `9`, with page `0` as default.
Pinned data does not prove component/page ownership, so the production graph
remains zone-owned with `page_id = nil`.

distinct native components and remain disconnected where native topology says
