# The Boyahda Tree (zone 153)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both Boyahda-side points of every exact physical handoff, Home Point #1,
all fourteen active coffer possibilities, and the exhaustive active static NM
catalog supported by the pinned CatsEyeXI source. The layer has 75 markers
across seven encounters: every scripted random-start position for five lottery
NMs, Ancient Goobbue's fixed timed position, and Agas's quest-pop position. No
transition or blocked-link exception is authored.

The supported destinations occupy six native components. The source topology
does not prove how the Tree's ledges, drops, doors, ramps, or vertically
separated regions connect, so no cross-component link is inferred from
proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
