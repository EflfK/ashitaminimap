exact handoff side, active coffer possibility, and supported NM start retains

1,694 nodes. Production metrics report no isolated node, six native edges
longer than 24 yalms, no edge steeper than four yalms, 294 projected
separated-elevation overlaps, and no substantial nearby-component lead.

Those overlaps and six disconnected destination-backed components are not
flattened into page assignments. Door and teleporter state must be verified
live before any exception or component ownership is authored.
