# Garlaige Citadel map provenance

- Zone: Garlaige Citadel (`200`)
- Stock pages: `1`, `2`, `3`, `14`, and `16`
- Collision/navigation: `Garlaige_Citadel.obj` and
  `Garlaige_Citadel.nav`
- Page 16 map record: scale byte `2`, offsets `(-352,-336)`
- Page 16 calibration: origin `(352,336)`, `0.40 px/yalm`,
  `80 yalms/cell`
- Page 16 Detour elevation band: `-21` through `-14`
- View bounds: complete `(0,0)-(512,512)` page

Garlaige reuses overlapping world coordinates across logical pages and has
navmesh connections between areas that the stock map displays separately.
Consequently, one zone-wide connected-component projection is not a truthful
structure layer. AshitaMinimap selects structure assets by the active stock
page and currently enables only the verified page 16 layer. Pages `1`, `2`,
`3`, and `14` intentionally retain vanilla-only fallback until their distinct
membership rules are verified.

```text
python tools/generate_walkable_map.py <OBJ> <NAV> \
  assets/maps/200_16_structure.png \
  --origin-x 352 --origin-y 336 --pixels-per-yalm 0.4 \
  --minimum-elevation -21 --maximum-elevation -14
```

The page-16 output was visually registered against `assets/vanilla/200_16.png`.
Its boundary follows the stock accessible region while omitting other Citadel
floors that project into the same 2D coordinate space.
