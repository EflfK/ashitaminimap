# Garlaige Citadel (zone 200)

## Status

Garlaige Citadel remains a routing-first **partial** map. The pinned navmesh
contains overlapping logical stock pages, native connections that cross stock
page boundaries, the three Banishing Gates, a one-way floor drop, and many
small disconnected surfaces. Those relationships cannot be reconstructed from
two-dimensional proximity or the dormant structure images.

Page 16 now has a mask-independent graph for every supported deterministic
destination on that page: all 50 Serket possibilities, the upper Grounds Tome,
and the active Treasure Chest at `(-352.798,266.998,15.602)`. Its two native
components remain separate because no attended entrance/midpoint/exit capture
proves the nearby vertical seam.

Page 1 retains its older calibrated mask-selected partial graph. It is not
recertified here as routing-complete. Pages 2, 3, and 14 remain vanilla-only.
The following evidence is still required before the zone can be complete:

- exact component-to-page membership for pages 1, 2, 3, and 14;
- attended traversal through each Banishing Gate and the one-way floor drop;
- page membership for the remaining active chest/coffer points and NMs; and
- focused entrance/midpoint/exit evidence for every destination-affecting
  source-navmesh gap.

No transition, one-way transition, or blocked link is authored without that
evidence. Unsupported destinations remain marker-only rather than being
assigned to a guessed page.

## Page-16 deterministic generation

The page-16 graph no longer depends on a structure mask. Its elevation band
retains the supported chest's source-floor component as well as the verified
live page-16 range. One exact representative selects each retained component:

```text
python tools/generate_path_graph.py <xiNavmeshes>/Garlaige_Citadel.nav \
  assets/paths/200_16.lua --zone-id 200 --page-id 16 \
  --minimum-elevation -21 --maximum-elevation -12 \
  --seed=-155,244,19 \
  --seed=-352.798,266.998,15.602
```

No mask, transition, one-way transition, or blocked link is used.
