# Windurst Woods map provenance

## Optional vanilla layer

`241_vanilla.png` is decoded directly from `<FFXI>/ROM/18/72.DAT`. The
Windurst Woods page occupies source rectangle `(0,0)-(350,512)`; the adjacent
composite page is transparent in this layer. Source alpha is normalized to
opaque so the addon's independent vanilla-opacity slider is a direct 0–100%
control.

```text
python tools/generate_vanilla_layer.py \
  <FFXI>/ROM/18/72.DAT \
  assets/maps/241_vanilla.png \
  --box 0,0,350,512
```

## Walkable structure (current)

`241_structure.png` is generated from LandSandBoat's explicit
`Windurst_Woods.obj` collision geometry and matching compiled Detour navmesh.
The OBJ is the coordinate-space reference; the navmesh selects traversable
polygons so flat but inaccessible collision surfaces, such as roofs, are not
shown as playable.

```text
python tools/generate_walkable_map.py \
  <xiNavmeshOBJs>/obj/Windurst_Woods.obj \
  <xiNavmeshes>/Windurst_Woods.nav \
  assets/maps/241_structure.png \
  --origin-x 108.5 \
  --origin-y 288.0 \
  --pixels-per-yalm 0.80 \
  --seed 15,0 \
  --exclude-box 0,360,61,371
```

The generator validates that both sources share an origin and keeps only the
Detour-connected component containing the verified walkable `(15, 0)` seed.
LandSandBoat Z is converted to Ashita world Y with `world_y = -nav_z` before
seeding and projection. It projects that polygon union through the verified
calibration, removes only tiny obstacle holes, and leaves true transparency
outside the accessible fill.

The exclusion rectangle trims the straight collision corridor that continues
past the useful Port Windurst transition endpoint. It stops before the curved
western approach and does not alter any interior walkable polygon.
Labels and landmarks remain independent optional overlays. See
`THIRD_PARTY_NOTICES.md` for source revisions and licensing.

## Source

- Zone: Windurst Woods (`241`)
- Vanilla DAT: `<FFXI>/ROM/18/72.DAT`
- Embedded page identifier: `m_241_00`
- Source dimensions: `512 × 512`
- Horizontal wrap: none

The source was decoded directly with `tools/generate_vanilla_map.py`. The
navigation and annotation layers retain identical source dimensions and pixel
coordinates.

## Legacy vanilla annotation layers

The optional annotation source retains the original vanilla pixel coordinates:

- `241_structure_source.png` preserves the former vanilla linework for
  provenance and rollback; it is not displayed by the current map.
- `241_labels_source.png` preserves the vanilla-derived annotation alpha.
- `241_labels.png` renders place and exit text in warm sand.
- `241_landmarks.png` renders static service and landmark symbols in amber.

The optional annotation files were generated with:

```text
python tools/style_dark_tactical_layers.py \
  assets/maps/241_structure_source.png \
  assets/maps/241_labels_source.png \
  assets/maps/241_structure.png \
  assets/maps/241_labels.png \
  assets/maps/241_landmarks.png \
  --label-box 0,110,108,134 \
  --label-box 155,156,286,181 \
  --label-box 70,190,135,231 \
  --label-box 225,210,310,248 \
  --label-box 138,273,215,296 \
  --label-box 202,286,274,320 \
  --label-box 266,310,350,344 \
  --label-box 84,330,174,374 \
  --label-box 263,337,350,372 \
  --label-box 0,288,45,316 \
  --label-box 0,420,116,455 \
  --label-box 137,408,235,452 \
  --landmark-box 133,222,156,251 \
  --landmark-box 38,345,62,376 \
  --landmark-box 91,356,116,385 \
  --landmark-box 207,336,234,368 \
  --landmark-box 166,383,194,413 \
  --landmark-box 116,420,140,450
```

The structure uses core source pixels only; it does not add a dilation halo.
The generator reconstructs the full extracted mask, moves only explicit text
and landmark rectangles to their optional layers, and removes faint decorative
grid strokes unless doing so would cut a crossing boundary. All rectangles use
source-pixel coordinates, so splitting the layers does not alter calibration.

## Extraction regions

The tactical linework includes source rectangle `(0,75)-(350,455)`. The
decorative compass at `(235,365)-(350,455)` is excluded. Navigation geometry is
limited to `(0,75)-(260,455)`.

Complete annotation rectangles, rather than whole-map glyph detection, are used
for location names, leader lines, and map icons:

```text
(0,110)-(108,134)    (155,156)-(286,181)
(70,190)-(135,231)   (225,210)-(310,248)
(138,273)-(215,296)  (202,286)-(274,320)
(266,310)-(350,344)  (84,330)-(174,374)
(263,337)-(350,372)  (0,288)-(45,316)
(0,420)-(140,455)    (137,408)-(235,452)
(133,222)-(156,251)  (38,345)-(62,376)
(91,356)-(116,385)   (207,336)-(234,368)
(166,383)-(194,413)  (116,420)-(140,450)
```

Explicit rectangles prevent small navigation components from being
misclassified as text and keep connected label/leader-line pixels together.

## Calibration

The vanilla coordinate grid is 32 source pixels per cell. Windurst Woods uses
40-yalm cells, producing:

```text
image_pixels_per_yalm = 32 / 40 = 0.80
```

The page is not horizontally wrapped. The decoded artwork grid is not a
reliable renderer origin for this page. With both minimaps set to the measured
stock scale of `3.13 px/yalm`, live NPC control points align while the custom
artwork is `130` screen pixels down and `4` screen pixels left. At
`3.13 / 0.80 = 3.9125` screen pixels per source pixel, this is a correction of
approximately `+33` source pixels vertically and `-1` horizontally:

```text
origin_x = 108.5
origin_y = 288.0
```

These source-image values are independent of viewport size and display zoom.
Calibrate against stock-rendered geometry only after matching zoom via live
entity control points; do not infer the renderer origin from decorative grid
pixels.
