# Windurst Woods map provenance

## Optional vanilla layer

`241_vanilla.png` is decoded directly from `<FFXI>/ROM/18/72.DAT`. The source
page wraps horizontally at x=366. A cyclic +146 px offset restores the missing
A-D section to the left of E-O, producing the complete 512 × 512 Windurst Woods
page. Source alpha is normalized to opaque so the addon's independent
vanilla-opacity slider is a direct 0–100% control.

The full rectangle `(0,0)-(512,512)` is stored as `view_bounds`, making the
complete vanilla page the maximum zoom-out view.
When the overview viewport reaches a page edge, the camera moves the player
off-center rather than hiding the opposite edge. This affects only screen
framing, not calibration.

```text
python tools/generate_vanilla_layer.py \
  <FFXI>/ROM/18/72.DAT \
  assets/maps/241_vanilla.png \
  --x-offset 146 \
  --box 0,0,512,512
```

## Walkable structure (current)

`241_structure.png` is generated from LandSandBoat's explicit
`Windurst_Woods.obj` collision geometry and matching compiled Detour navmesh.
The OBJ is the coordinate-space reference; the navmesh selects traversable
polygons so flat but inaccessible collision surfaces, such as roofs, are not
shown as playable.

```text
python tools/generate_walkable_map.py \
  <xiNavmeshOBJs>/obj/Windurst_Woods.obj \
  <xiNavmeshes>/Windurst_Woods.nav \
  assets/maps/241_structure.png \
  --origin-x 254.5 \
  --origin-y 288.0 \
  --pixels-per-yalm 0.80 \
  --seed 15,0 \
  --exclude-box 146,360,207,371
```

The generator validates that both sources share an origin and keeps only the
Detour-connected component containing the verified walkable `(15, 0)` seed.
LandSandBoat Z is converted to Ashita world Y with `world_y = -nav_z` before
seeding and projection. It projects that polygon union through the verified
calibration, removes only tiny obstacle holes, and leaves true transparency
outside the accessible fill.

The exclusion rectangle trims the straight collision corridor that continues
past the useful Port Windurst transition endpoint. It stops before the curved
western approach and does not alter any interior walkable polygon.
See `THIRD_PARTY_NOTICES.md` for source revisions and licensing.

## Source

- Zone: Windurst Woods (`241`)
- Vanilla DAT: `<FFXI>/ROM/18/72.DAT`
- Embedded page identifier: `m_241_00`
- Source dimensions: `512 × 512`
- Horizontal unwrap offset: `+146 px`

The source was decoded directly with `tools/generate_vanilla_map.py`. The
vanilla and walkable-structure layers retain identical source dimensions and
pixel coordinates. `241_structure_source.png` preserves the former vanilla
linework for provenance and rollback; it is not displayed by the addon.

## Calibration

The vanilla coordinate grid is 32 source pixels per cell. Windurst Woods uses
40-yalm cells, producing:

```text
image_pixels_per_yalm = 32 / 40 = 0.80
```

After the +146 px horizontal unwrap, the decoded artwork grid is not itself a
reliable navigation-geometry origin. Live NPC control points establish:

```text
origin_x = 254.5
origin_y = 288.0
```

These source-image values are independent of viewport size and display zoom.
The vanilla artwork's H-8 grid center is `(255, 256)`, so the renderer stores
that as a separate grid origin. It must not use the geometry origin `(254.5,
288)` for quadrant labels; doing so shifts every displayed row down by one.
Calibrate against stock-rendered geometry only after matching zoom via live
entity control points; do not infer the renderer origin from decorative grid
pixels.
