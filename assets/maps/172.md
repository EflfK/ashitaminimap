# Zeruhn Mines (zone 172)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for the main mine network and the exact Korroloka zoning threshold. It
requires no structure image and authors no transition or blocked-link
exception.

Two source questions block a completion claim:

- the 74-node Korroloka threshold does not join the 837-node main network; and
- an unselected 173-node interior strip lies close to the main network but has
  no exact handoff or supported destination proving player accessibility.

Neither component is joined from proximity. The interior strip remains
unresolved until collision inspection or focused live traversal proves
whether it is a public walkway, mine rail surface, or inaccessible geometry.

## Page and floor scope

The imported stock catalog identifies one page, `m_172_00`. No alternate stock
page is present. The selected graph preserves Detour elevation in 3D, has no
stacked-floor overlaps, and does not flatten the deeper Korroloka threshold
into the main mine network.

All published destinations therefore use page `0`; the ordinary mine network
is labeled the main mine floor. There is no NM floor/page ambiguity to resolve
because the exhaustive active NM catalog is empty at the pinned revision.

Runtime stock calibration should remain authoritative through
`stock_calibration = true`. The installed `FFXiMain.dll` did not expose the
expected static table signature and AshitaMCP was unavailable during this
audit, so the exact page-0 scale byte and signed offsets remain unresolved.
This also prevented live close/overview calibration and off-route recovery
tests.
