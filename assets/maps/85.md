## Status

This is a routing-first **partial** map. It publishes the main exterior/fortress
component, three exact upper gateway regions, and one NM-supported fragment.
Campaign controls, gates, doors, drops, and event relocations remain unlinked
without verified before/after endpoints.

zone-owned (`page_id = nil`) and should use `stock_calibration = true`.
