# The Shrine of Ru'Avitau (zone 178)

## Status

This is a routing-first **partial** map. It retains every native Detour
component selected by an exact zone handoff, the active Home Point, a relevant
fixed/triggered NM, or one pinned nonzero active-mob control per otherwise
unrepresented source component. It does not invent links for Cermet Doors,
monoliths, teleporters, elevators, floor changes, or navmesh seams.

The stock catalog contains pages `0`, `1`, `2`, `3`, `4`, `5`, and `15`, with
page `0` as default. Pinned data does not assign retained components to those
pages, so the production graph remains zone-owned with `page_id = nil`.
