# Batallia Downs [S] (zone 84)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for all exact physical threshold regions, the Survival Guide, three fixed
Treasure Coffers, the Cavernous Maw destination region, and four supported
static NMs. No transition, one-way transition, or blocked-link exception is
authored.

The stock catalog contains only page `0`, which is also the default. The graph
is zone-owned (`page_id = nil`) and shared integration should retain live stock
calibration through `stock_calibration = true`.
