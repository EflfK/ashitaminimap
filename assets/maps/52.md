# Bhaflau Thickets (zone 52)

## Status

This is a routing-first **partial** map. It publishes the native Detour
components selected by every exact physical zone threshold, Home Point #1,
and the exhaustive active NM catalog supported by the pinned CatsEyeXI tree.
The layer has 176 markers across six encounters: four ordinary random-start
NMs and both active item-triggered ZNMs. No transition, one-way transition, or
blocked-link exception is authored.

The stock catalog contains pages `1` and `2` and defaults to page `1`. No
truthful page-membership evidence was found for the disconnected navigation
components, so the graph remains zone-wide and no `page_rules` or
`page_graph_seeds` are claimed. Both pages should retain live stock
calibration through `stock_calibration = true`.
