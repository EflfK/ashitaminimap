# La Theine Plateau (zone 102)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact physical world handoff, the Survival Guide, and pinned active
fixed NMs without requiring or generating a structure image. No transition or
blocked-link exception is authored.

The main outdoor surface is connected, but all three Ordelle's Caves
thresholds and Tumbling Truffle's elevated area remain separate source
components. The three Ordelle components each have a nearby-component review
lead; proximity is not proof of a traversable ramp, drop, or tunnel mouth.
They remain marker-only from the main surface pending focused attended
entrance, midpoint, and exit captures.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but the numeric scale and offsets must be recorded before the map can be
described as fully calibrated.
