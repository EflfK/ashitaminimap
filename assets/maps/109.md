# Pashhow Marshlands (zone 109)

## Status

This is a routing-first **partial** map. It publishes the single native Detour
component containing every exact world handoff, the active Survival Guide, and
all supported fixed-NM source positions. It requires no structure image and
authors no transition or blocked-link exception.

The retained network gives route coverage between all supported fixed
destinations. However, the unseeded navmesh contains five additional
components larger than 1,000 nodes. Pashhow's marsh channels, raised banks, and
bridges make those components potentially route-relevant. They remain
unselected and unresolved because no trustworthy destination or live interior
point proves their accessibility. No bank or bridge is connected from
two-dimensional proximity.

## Stock calibration

The imported stock catalog has one page, page `0`. Runtime
`stock_calibration = true` is authoritative for the exact FFXiMain map-table
scale and origin. This session did not have a pinned static capture of the
page-0 numeric record, so its scale byte and offsets remain a provenance
blocker rather than being guessed.

## Native-component review

The unseeded native graph has 17,494 nodes, 19,350 edges, and 332
components. The production selector retains one 4,539-node component with
5,304 bidirectional edges.

That retained component contains:

- both sides of the Konschtat Highlands, Rolanberry Fields, and Beadeaux
  handoffs;
- the Survival Guide; and
- every supported fixed-NM source position listed below.

The 331 excluded components contain no exact supported seed. The largest have
3,261, 2,317, 1,778, 1,467, 1,326, 789, 317, 304, 239, 167, 129, and 102
nodes. The first five are substantial enough to affect ordinary marsh travel
or bridge approaches and block a completion claim. They require deterministic
collision/graph-web review and focused live interior or bridge samples; they
must not be promoted merely because their projected edges are near the
retained network.

All supported endpoints snap within 5.443 yalms of the selected graph. No
global snap-radius change is needed.
