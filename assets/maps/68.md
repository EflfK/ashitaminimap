# Aydeewa Subterrane (zone 68)

## Status

This is a routing-first **partial** map. It retains nineteen native Detour
components selected by every exact physical zone handoff, supported quest and
excavation destinations, mushroom patches, the Survival Guide, and supported
static NMs. It does not invent links across doors, gates, drops, zone changes,
event relocations, or other transport mechanisms.

The stock catalog has pages `1` through `7`, with page `1` as default. No
truthful component-to-page evidence was found, so the graph remains zone-owned
(`page_id = nil`) and all pages retain live stock calibration through
`stock_calibration = true`.
