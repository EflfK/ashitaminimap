# Yhoator Jungle (zone 124)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for the active Survival Guide, both sides of every exact world handoff, and
all supported pinned NM spawn ranges. It requires no structure image and
authors no transition or blocked-link exception.

Yhoator Jungle has cliffs, isolated temple thresholds, and separated jungle
pockets. The supported destinations select eight disconnected native
components. No cliff, drop, cave, or cross-height connection is inferred from
projected X/Y proximity.

## Stock calibration

The imported stock catalog has one page, page `0`. Runtime
`stock_calibration = true` is authoritative for the exact FFXiMain map-table
scale and origin. This session did not have a pinned static capture of the
numeric page-0 record, so its scale byte and offsets remain a provenance
blocker rather than being guessed.
