# Jugner Forest (zone 104)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact physical handoff, the Survival Guide, and pinned fixed NMs
without requiring or generating a structure image. No transition or
blocked-link exception is authored.

The main forest network is connected across its native bridges and river
crossings. King Arthro's water component, both Carpenter's Landing thresholds,
and the King Ranperre's Tomb threshold remain separate source components.
They remain marker-only from the main network pending attended
entrance/midpoint/exit evidence. In particular, no bank-to-bank or
bridge-to-water connection is inferred from proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
