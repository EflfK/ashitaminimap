# Meriphataud Mountains (zone 119)

## Status

This is a routing-first **partial** map. One native Detour component contains
every supported public handoff, the Survival Guide, and all five pinned fixed
NM references. It requires no structure image and authors no transition or
blocked-link exception.

The supported network is connected, but four evidence gaps block a completed-
map claim:

- the exact outbound Sauromugue record is 41.806 yalms from a floor-compatible
  graph node, although its paired arrival record snaps;
- the exact outbound Sanctuary of Zi'Tah record is 83.915 yalms from a
  floor-compatible graph node, although its paired arrival record snaps;
- one native edge has a 4.033-yalm elevation delta and requires focused review
  as a possible long slope or bad source edge; and
- substantial excluded cliff/shelf components near supported terrain cannot be
  classified as public or inaccessible without collision or live evidence.

No component or threshold is joined from proximity.

## Page and calibration scope

The imported stock catalog identifies one page, `m_119_00`; no alternate stock
page is present. Runtime stock calibration should remain authoritative through
`stock_calibration = true`.

The installed `FFXiMain.dll` did not expose the expected static table
signature and AshitaMCP was unavailable during this audit, so the exact scale
byte and signed page-0 offsets remain unresolved. Live close/overview
calibration and off-route recovery could not be tested.
