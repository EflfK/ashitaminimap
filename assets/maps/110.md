# Rolanberry Fields (zone 110)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact physical handoff, the Survival Guide, and all six supportable
active NMs with their complete pinned spawn behavior. No structure image,
transition, or blocked-link exception is authored.

The main field network is connected. The southwest plateau containing
Drooling Daisy, Simurgh, and the western Crawler's Nest threshold is a
separate source component. The southern Crawler's Nest threshold is another
small source component. Both remain marker-only from the main network pending
attended entrance/midpoint/exit evidence. Two tiny native components are also
retained for the isolated scripted Eldritch Edge starts; no synthetic links
are added for them.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
