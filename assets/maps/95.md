# West Sarutabaruta [S] (zone 95)

## Status

This is a routing-first **partial** map. It publishes the single large native
component selected by exact physical handoffs. Campaign controls, the Cavernous
Maw, sealed entrances, transports, drops, and event relocations remain unlinked
without verified before/after endpoints.

The stock catalog contains only page `0`, which is the default. The graph is
zone-owned (`page_id = nil`) and should use `stock_calibration = true`.

## Native component selection

The unseeded native graph has 13,914 nodes, 15,015 bidirectional edges, and
1,059 components, including 581 isolated nodes. The first exact physical
handoff selects the only supported useful component: 11,340 nodes and 13,460
edges. The other 1,058 components lack a supported routing selector. `qm1`
selects a five-node fragment without supported behavior or useful route extent;
the Stone Monument selects an isolated node. Both are omitted.

## Physical handoffs and controlled destinations

Two paired boundaries are supported: East Sarutabaruta [S] at
`(320.018,-45.166,-6.684)` / `(320.010,-48.071,-8.222)`, and Fort Karugo-Narugo
[S] at `(120.000,640.000,-26.001)` / `(118.936,648.841,-27.623)`. The zone
default equals the East Sarutabaruta [S] incoming sample. These samples select
the main component but do not create cross-zone graph edges.

Exact records for `_2n0`, three Sealed Entrances, and the Cavernous Maw remain
destinations only. No source proves their ordinary walking connectivity,
directionality, or relocation endpoints. Campaign coffers, fortifications,
sentries, commissaries, reinforcements, transporters, campaign forces,
Voidwatch/Voidwalker actors, pets, helpers, and event actors are not routing
transitions.
