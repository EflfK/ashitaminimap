# Rolanberry Fields [S] (zone 91)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for all six exact physical boundary regions, the Survival Guide, the Cavernous
Maw destination, four supported static NM families, and two substantial
components backed by ordinary non-campaign mobs. No transition, one-way
transition, gate, transport, or drop exception is authored.

The stock catalog has only page `0` and defaults to page `0`. The graph is
zone-owned and shared integration should retain live stock calibration with
`stock_calibration = true`.

entrance/midpoint/exit evidence.
