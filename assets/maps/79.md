# Caedarva Mire (zone 79)

## Status

This is a routing-first **partial** map with an exhaustive static NM catalog.
It publishes native Detour topology
for all exact physical handoffs, Home Point #1, the Survival Guide, and the
supported active static NM records. No transition, one-way transition, or
blocked-link exception is authored.

The stock catalog contains pages `1` through `4` and defaults to page `1`.
The pinned sources do not prove component-to-page membership, so the graph is
zone-wide and no page rules or page graph seeds are claimed. Catalog
integration should retain live stock calibration.
