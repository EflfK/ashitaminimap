# Davoi map provenance

## Stock page and calibration

- Zone: Davoi (`149`)
- Imported stock page: `assets/vanilla/149_00.png`
- Stock page: `0`, 512 × 512
- Exact FFXiMain map record: scale byte `2`, offsets `(-240,-208)`
- Navigation origin: `(240,208)`
- Printed-grid origin: `(255,256)`
- Scale: `0.40 px/yalm`
- Grid: `80 yalms/cell`
- View bounds: complete `(0,0)-(512,512)` page

The stock record was captured through AshitaMinimap's read-only FFXiMain table
lookup while the player was live in Davoi. The live fallback reported page `0`,
scale byte `2`, origin `(240,208)`, and the matching signed offsets.

Generate the ground structure while excluding the separately rendered raised
east platform:

```text
python tools/generate_walkable_map.py <Davoi.obj> <Davoi.nav> \
  assets/maps/149_structure.png \
  --origin-x 240 --origin-y 208 --pixels-per-yalm 0.4 \
  --exclude-seed=186.125,-107.558 \
  --minimum-island-area 6
python tools/generate_walkable_map.py <Davoi.obj> <Davoi.nav> \
  assets/maps/149_elevated_structure.png \
  --origin-x 240 --origin-y 208 --pixels-per-yalm 0.4 \
  --seed=186.125,-107.558 \
  --fill-rgb 42,30,66 --edge-rgb 181,132,255
```

Together the outputs contain all 4,960 Detour polygons. The ground render
removes 229 disconnected raster islands smaller than six output pixels; these
are isolated navmesh specks rather than meaningful paths. At the standard
`0.65` maximum step, the source polygons form 521 seam-connected components:

| Polygon count | Components |
| ---: | ---: |
| 100 or more | 4 |
| 20–99 | 3 |
| 5–19 | 78 |
| 1–4 | 436 |

The seven largest components contain 2,950, 216, 130, 129, 88, 86, and 29
polygons. Most smaller components are terrain slopes, landings, or fragments
separated by sub-yalm Detour seams. Davoi has one stock page and one logical
floor; most elevation changes are ordinary terrain rather than another map.
The inaccessible raised east platform is the one confirmed exception: it is a
separate same-page violet component so its projected boundary cannot imply a
ground-level connection.

## Treasure Chest references

Davoi has 12 fixed possible Treasure Chest positions. They come from
CatsEyeXI's public `scripts/globals/treasure.lua` at commit
`314deaf03465f2b24b6a1e4e73a016ca036f1084`. Source tuples use
`(x, vertical, horizontal, rotation)` and are converted to minimap
`(x, horizontal, vertical)`.

These gold markers are static possibilities. They do not inspect the chest,
identify the occupied point, or imply that a chest is currently present.
