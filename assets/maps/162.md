# Castle Zvahl Keep (zone 162)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for the Home Point, active fixed Treasure Chest possibility, both physical
zone handoffs, and all four supported NM spawn ranges. No transition,
blocked-link, door, drop, elevator, or teleporter exception is authored.

The stock catalog contains pages `0` through `4`, with page `0` as the
default. Exact runtime page switching and numeric page calibration were not
captured. The graph is therefore zone-wide and stock calibration remains
authoritative.
