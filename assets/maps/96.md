# Fort Karugo-Narugo [S] (zone 96)

## Status

This is a routing-first **partial** map. It publishes six independently
supported native Detour components selected by exact physical boundaries,
the Survival Guide, fixed Treasure Coffers, logging points, four supported
static NMs, and ordinary non-campaign spawn coverage. No transition, one-way
transition, door, gate, campaign, transport, or drop exception is authored.

The stock catalog contains pages `1` and `2`, with page `1` as the default.
The graph is deliberately zone-owned (`page_id = nil`) pending attended stock
calibration and proof of component-to-page membership. Shared integration
should use `stock_calibration = true` and no page rule.

## Native component selection

The unseeded native graph has 13,937 nodes, 14,316 bidirectional edges, and
1,138 components, including 485 isolated nodes. Exact supported selectors and
ordinary non-campaign spawn coverage retain 9,270 nodes, 10,572 edges, and
six components:

```text

```

The 7,973-node main component contains three Meriphataud boundaries, the
West Sarutabaruta arrival, the fallback arrival, Survival Guide, Stone
Monument, western logging region, and all four supported NMs. The 357-node
eastern logging region, 294-node coffer region, six-node eastern Meriphataud
threshold, and three-node West Sarutabaruta outbound threshold are retained
from exact evidence. The 637-node eastern region is retained from 18 ordinary
non-campaign spawns. The ordinary-spawn threshold is 40 nodes.

The other 1,132 source components lack supported selectors or are below the
ordinary-coverage threshold and remain unclassified. In particular, a
573-node alternate-elevation fort network contains campaign actors and many
door-side records, but no exact evidence proves a traversable connection to
the published main network. It remains excluded rather than being joined
across doors or vertical proximity.
