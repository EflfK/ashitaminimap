# Konschtat Highlands (zone 108)

## Status

This is a routing-first **partial** map. It publishes the single native Detour
component containing every exact client world handoff, the active Survival
Guide, and all supported ordinary-NM source positions. It requires no
structure image and authors no transition or blocked-link exception.

The selected topology spans the zone's large elevation range without joining
polygons from projected X/Y proximity. The Valkurm Dunes threshold is retained
by its exact handoff seeds, but its nearest same-floor polygon centroid remains
outside the runtime snap radius. Focused attended threshold and ravine/bridge
review remains necessary before calling the map complete.

## Stock calibration

The imported stock catalog has one page, page `0`. Runtime
`stock_calibration = true` is authoritative for the exact FFXiMain map-table
scale and origin. This session did not have a pinned static capture of the
page-0 record values, so the numeric scale byte and offsets remain a provenance
blocker rather than being guessed.
