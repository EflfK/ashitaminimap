# Ro'Maeve (zone 122)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both exact physical handoffs, the Survival Guide, and every supported
static NM possibility for which the source has usable navigation coverage.
It does not require or generate a structure image and authors no transition,
one-way transition, or blocked-link exception.

The graph retains three disconnected native components because each contains
an exact supported destination. Four Rogue Receptacle possibilities have no
source node within the runtime snap radius and remain marker-only. Completion
requires attended Moongate/bridge-state review, the substantial overlapping
component lead, the remaining native long edge, and live route/recovery tests.
