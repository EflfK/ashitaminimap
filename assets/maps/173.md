# Korroloka Tunnel (zone 173)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for all three verified physical handoffs, the Survival Guide teleport
destination, and every supported NM start. No transition, blocked-link, door,
waterway, or page-ownership exception is authored.

The imported stock assets contain pages `0`, `1`, `2`, `3`, `4`, and `5`.
The pinned sources do not deterministically assign the retained components to
those pages. The graph therefore remains zone-wide and stock runtime page
selection remains authoritative.
