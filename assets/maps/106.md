# North Gustaberg (zone 106)

## Status

This is a routing-first **partial** map. It publishes conservative native
Detour topology for every exact client world handoff, the active Survival
Guide, and the fixed initial-spawn NM references supported by the pinned
CatsEyeXI records. It requires no structure image and authors no transition or
blocked-link exception.

The production selector intentionally preserves five disconnected source
components. North Gustaberg has large elevation changes around Drachenfall,
the river basin, western cliffs, and multiple bridge approaches. No connection
between those components is inferred from projected X/Y proximity. Focused
attended entrance/midpoint/exit captures are still required before any missing
bridge, slope, or zoning-threshold connection can be authored.

## Stock calibration

The imported stock catalog has one page, page `0`. Runtime
`stock_calibration = true` is authoritative for the exact FFXiMain map-table
scale and origin. This session did not have a pinned static capture of the
page-0 record values, so the numeric scale byte and offsets remain a provenance
blocker rather than being guessed.

components. The production selector retains 12,852 nodes, 14,551 edges, and

| 3,019 | Western field; Survival Guide and western South Gustaberg handoff |
| 857 | Konschtat Highlands zoning threshold |
| 453 | Elevated Stinging Sophie basin |
| 406 | Dangruf Wadi zoning threshold/high plateau |

The 1,809 excluded components contain no exact handoff or supported fixed
destination seed. The largest excluded components have 783, 226, 186, 147,
144, 124, 122, 117, and 105 nodes. Because the 783-node component and the five
retained networks could plausibly participate in the river, bridge, or
elevation topology, they remain unresolved and block a completion claim.
No component is promoted from two-dimensional proximity.

The western South Gustaberg handoff at
`(-440.639,-276.308,33.094)` is retained, but its nearest same-floor polygon
centroid is 34.201 yalms away, outside the production 24-yalm snap radius.
That handoff remains marker-only pending focused threshold evidence rather
than globally weakening endpoint snapping.
