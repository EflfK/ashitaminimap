# North Gustaberg (zone 106)

## Status

This is a routing-first **partial** map. It publishes conservative native
Detour topology for every exact client world handoff, the active Survival
Guide, and every scripted NM possibility supported by the pinned CatsEyeXI
records, including the active Garrison boss. It requires no structure image
and authors no transition or blocked-link exception.

The production selector intentionally preserves six disconnected source
components. North Gustaberg has large elevation changes around Drachenfall,
the river basin, western cliffs, and multiple bridge approaches. No connection
between those components is inferred from projected X/Y proximity. Focused
attended entrance/midpoint/exit captures are still required before any missing
bridge, slope, or zoning-threshold connection can be authored.

## Stock calibration

The imported stock catalog has one page, page `0`. Runtime
`stock_calibration = true` is authoritative for the exact FFXiMain map-table
scale and origin. This session did not have a pinned static capture of the
page-0 record values, so the numeric scale byte and offsets remain a provenance
blocker rather than being guessed.
