# Quicksand Caves (zone 208)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact world handoff, both Home Points, all active coffer
possibilities, and conservative nonzero initial-spawn NM records without
requiring or generating a structure image. No transition or blocked-link
exception is authored.

The supported destinations occupy nineteen native components. This is
consistent with Quicksand Caves' many isolated desert entrances, weighted
doors, drops, and vertically stacked regions, but source geometry alone does
not prove how those mechanisms connect. No door, fall, elevator, stair, ramp,
or floor handoff is inferred from proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
