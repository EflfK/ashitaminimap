# Beadeaux map provenance

## Completion status

Beadeaux is an installed audit build, not yet a completed production map.
Pages `1` and `15` have deterministic structure and page-owned path artifacts.
Stock page `16` is a `Dummy Map` and remains vanilla-only until an attended
traversal proves whether the client assigns reachable geometry to it.

The following completion evidence is still required:

1. traverse every page-1 path, lower area, stair, ramp, and projected crossing;
2. traverse both page-15 tunnel networks and every transition between live
   player-Z bands;
3. capture entrance, midpoint, and exit X/Y/Z for each transition;
4. observe the active stock page throughout the route, including every
   page-15 transition, to resolve page `16`;
5. classify the remaining nearby Detour fragments as connector or excluded;
6. validate endpoint snapping, connected routes, deliberately disconnected
   targets, off-route recovery, and close-zoom path alignment in game.

Do not replace this section with a completeness claim until every item is
recorded below.

## Structure generation

Page 1 currently retains five deterministic components proven by the pinned
Survival Guide, chest, or NM records. The overlapping lower network is kept in
a separate violet texture:

```text
python tools/generate_walkable_map.py <Beadeaux.obj> <Beadeaux.nav> \
  assets/maps/147_01_main_structure.png \
  --origin-x 272 --origin-y 256 --pixels-per-yalm 0.4 \
  --minimum-elevation -9 --maximum-elevation 5 \
  --seed=81.814,1.523 --seed=-184,-136 --seed=90.6,189.5 \
  --seed=-264,107 --seed=122.451,132.482

python tools/generate_walkable_map.py <Beadeaux.obj> <Beadeaux.nav> \
  assets/maps/147_01_lower_structure.png \
  --origin-x 272 --origin-y 256 --pixels-per-yalm 0.4 \
  --minimum-elevation 5 --maximum-elevation 13 \
  --seed=47.1665,231.362 \
  --fill-rgb 42,30,66 --edge-rgb 181,132,255
```
