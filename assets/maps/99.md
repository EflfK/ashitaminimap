# Castle Oztroja [S] (zone 99)

## Status

This is a routing-first **partial** map. It publishes four independently
supported native Detour components selected by the exact Meriphataud boundary,
eleven supported static NMs, and ordinary non-campaign spawn coverage. No
campaign, door, gate, trap, transport, drop, transition, one-way transition,
or blocked-link exception is authored.

The stock catalog contains pages `1` through `6`, with page `1` as the default.
The graph is deliberately zone-owned (`page_id = nil`) pending attended stock
calibration and proof of component-to-page membership. Shared integration
should use `stock_calibration = true` and no page rule.

## Native component selection

The unseeded native graph has 5,257 nodes, 5,402 bidirectional edges, and 312
components, including 139 isolated nodes. Exact supported selectors and
ordinary non-campaign spawn coverage retain 3,251 nodes, 3,576 edges, and four
components:

```text

```

The 1,615-node lower network contains Dee Zelko, Marquis Forneus, Loo Kutto,
Fleshgnasher, Maa Illmu, and Asterion, and is supported by 162 ordinary spawn
records. The 1,599-node upper network contains the Meriphataud boundary and
fallback, Zhuu Buxu, Vee Ladu, and Suu Xicu, and is supported by 118 ordinary
spawn records. The 21-node Aa Xalmo region and 16-node Duu Masa region are
retained from their exact scripted spawn points; each also has two ordinary
spawn records. The ordinary-spawn threshold is 40 nodes, but exact supported
destinations retain smaller components.

The other 308 source components, containing 2,006 nodes, lack supported
selectors or are below the ordinary-coverage threshold and remain
unclassified. An eight-node ordinary-spawn fragment is not promoted. No
proximity, overlapping floors, door-side records, traps, or campaign actors
are used to connect or select components.
