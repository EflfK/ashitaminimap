# Eastern Altepa Desert (zone 114)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact physical handoff, the Survival Guide, and every supported
static initial-spawn NM record without requiring or generating a structure
image. No transition or blocked-link exception is authored.

The main desert is connected. Four zoning thresholds and six exact NM start
points select ten additional source components. They remain separate pending
attended entrance/midpoint/exit evidence; two-dimensional proximity is not
used to invent seams.

The stock catalog contains page `0`, which is also the default page. Runtime
stock calibration remains authoritative through `stock_calibration = true`.

## Shared-catalog integration

The path graph registration is already present and requires no shared change:

```lua
[114] = 'assets/paths/114.lua',
```

The existing `GraphJob` already uses `Eastern_Altepa_Desert.nav`, output
`114.lua`, zone `114`, and the 11 seeds in the deterministic generation
command above. It requires no shared change.

The existing map catalog uses `stock_calibration = true`, the Survival Guide
record above, `treasure_spawns = {}`, and six `nm_spawn_ranges` records. For
the three random-start ranges, convert exactly the 50 entries from each pinned
`spawnPoints` array as described above; use `floor = 'SURFACE'`, the level and
type metadata in the table, and a default 4.5-yalm marker radius. The pinned
source vertical coordinate varies with desert terrain, so catalog integration
should preserve the exact live Z values in its source audit even though the
current display schema accepts only one floor reference Z per range.
