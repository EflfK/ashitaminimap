# Castle Zvahl Baileys [S] (zone 138)

## Status

This is a routing-first **partial** map. It publishes seventeen independently
supported native Detour components selected by exact physical boundaries, the
zone fallback, the Survival Guide, one supported notorious-monster group, and
ordinary non-campaign spawn coverage. No campaign, door, gate, transport,
drop, transition, one-way transition, or blocked-link exception is authored.

The stock catalog contains pages `1` through `4`, with page `1` as the default.
The graph is deliberately zone-owned (`page_id = nil`) pending attended stock
calibration and proof of component-to-page membership. Shared integration
should use `stock_calibration = true` and no page rule.
