# Gusgen Mines (zone 196)

## Status

This is a routing-first **partial** map. The graph contains only native Detour
components selected by exact world handoffs or supported CatsEyeXI
destinations. It does not bridge doors, shafts, elevators, one-way drops,
overlapping floors, or navmesh seams. No structure image is required.

The ordinary NM layer covers every active pinned ordinary, mission, and quest
NM position, with stock-page membership for pages `1`, `14`, `15`, and `16`.
Page `17` contains no supported NM. Completion still requires attended
traversal captures for every route-affecting door, drop, lift, and seam;
classification of the excluded native components; and a live reload with
route/recovery checks. Cross-component destinations remain marker-only.
