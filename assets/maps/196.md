# Gusgen Mines (zone 196)

## Status

This is a routing-first **partial** map. The graph contains only native Detour
components selected by exact world handoffs or supported CatsEyeXI
destinations. It does not bridge doors, shafts, elevators, one-way drops,
overlapping floors, or navmesh seams. No structure image is required.

Completion requires live page membership for stock pages `1`, `14`, `15`,
`16`, and `17`; attended traversal captures for every route-affecting door,
drop, lift, and seam; classification of the excluded native components; and a
live reload with route/recovery checks. Cross-component destinations remain
marker-only.
