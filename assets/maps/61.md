# Mount Zhayolm (zone 61)

## Status

This is a routing-first **partial** map. It publishes eighteen native Detour
components selected by exact physical handoffs, the Lebros arrival, active
fixed destinations, Home Point #1, mining, and supported static NMs. It does
not invent links across drops, Gates of Halvung, the Heavy Iron Gate, the
Acid-eaten Door, Runic transports, tablets, staging controls, or zone changes.

The stock catalog has only page `0`, which is also the default. The graph stays
zone-owned (`page_id = nil`), while the stock image should remain authoritative
through `stock_calibration = true` until live calibration is captured.

## Travel, treasure, and NMs

- Home Point #1: `(-540.844,70.809,-4.000)`, unlock index `90`
- Active SQL Home Point sample: `(-533.000,56.500,-4.099)`
- Survival Guides: verified empty
- Fixed Treasure Chests and Coffers: verified empty

Publish four supported static NM references:

| Name | Level | Type | Exact possibilities |
|---|---:|---|---:|
| Ignamoth | 84 | Lottery | 1 spawn point, 2 placeholders |
| Energetic Eruca | 80 | Lottery/random start | 50 spawn points, 2 placeholders |
| Chary Apkallu | 76-77 | Timed initial marker | 1 SQL point |
| Cerberus | 85 | Timed | 1 SQL point |

Chary Apkallu calls `updateNMSpawnPoint` after despawn, but no exact random
range is exposed; its SQL point remains an initial marker rather than a claim
of exhaustive coverage. Cerberus has explicit timed respawn behavior.

Brass Borer, Claret, Anantaboga, Khromasoul Bhurborlor, and Sarameya are
force-pop ZNMs and are excluded from the static catalog. Dark Rider and its
entourage, Voidwatch/Unity actors, Sarama and adds, ordinary high-level mobs,
pets, helpers, moogles, zero/dummy records, and event actors are also excluded.
Fahrafahr the Bloodied is explicitly labeled an NM, but the pinned sources do
not expose activation behavior; the Garharlor/Garfurlar/Garhorlur records also
lack explicit NM behavior. They remain attended/source-review blockers rather
than guessed spawn types.

  854.387 graph yalms.

mismatch, the four published NMs, excluded named mobs, long routes, and
