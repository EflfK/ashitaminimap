# Beadeaux [S] (zone 92)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for the exact Pashhow Marshlands [S] threshold and eleven supported static NM
records across three interior regions. No transition, one-way transition, or
blocked-link exception is authored.

The stock catalog contains pages `1` and `15` and defaults to page `1`. The
pinned sources do not prove component-to-page membership, so the graph remains
zone-owned (`page_id = nil`) and no page rules or page graph seeds are claimed.
Shared integration should retain live stock calibration.
