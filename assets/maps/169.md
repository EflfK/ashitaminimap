# Toraimarai Canal (zone 169)

## Status and pages

This is a routing-first **partial** map. Pages `1` and `2` use exact runtime
`FFXiMain.dll` stock calibration and share one three-dimensional graph. Page
`1` has scale byte `2` and origin `(320,272)`; page `2` has scale byte `2` and
origin `(192,240)`.

Existing live evidence assigns the previously retained Inner Horutoto,
Survival Guide, Home Point, Canal Moocher, and Oni Carcass components to page
`1`, and the Windurst Walls, first coffer position, Konjac, and Brazen Bones
components to page `2`. This audit adds native components for other exact
coffer positions and active-mob controls, but has no live evidence for their
page ownership. The production graph therefore remains zone-owned with
`page_id = nil`; no additional page rules are inferred.

multi-elevation waterways remain disconnected wherever native topology does.
