# North Gustaberg [S] (zone 88)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both exact physical boundaries, the Survival Guide, the Cavernous Maw
destination, the Lycopodium and mining references, three supported static NM
families, and substantial components backed by ordinary non-campaign mobs.
No transition, one-way transition, or blocked-link exception is authored.

The stock catalog has only page `0` and defaults to page `0`. The graph is
zone-owned and shared integration should retain live stock calibration with
`stock_calibration = true`.

1,762 components, including 878 isolated nodes. Exact supported selectors and
ordinary non-campaign spawn coverage retain 15,067 nodes, 17,404 edges, and

13-node Lycopodium region, and 9-node second mining region are retained from
exact evidence regardless of size. The other 1,753 components lack supported
selectors or are below the ordinary-coverage threshold and remain
unclassified, so this map is partial.

Six nearby-component review leads remain. The closest is 5.185 yalms planar
and 5.900 yalms in elevation between the 1,025- and 3,351-node components.
None is promoted to a stair, ramp, drop, gate, or other transition without
attended entrance/midpoint/exit evidence.
