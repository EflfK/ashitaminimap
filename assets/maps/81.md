# East Ronfaure [S] (zone 81)

## Status

This is a routing-first **partial** map. It publishes the native Detour
components selected by every exact physical handoff, the Survival Guide, the
Cavernous Maw, and four supported static NM records. No transition, one-way
transition, or blocked-link exception is authored.

The stock catalog contains only page `0`, which is also the default. The graph
is zone-owned (`page_id = nil`) and shared integration should retain live stock
calibration with `stock_calibration = true`.
