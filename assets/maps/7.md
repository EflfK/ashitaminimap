# Attohwa Chasm (zone 7)

## Status

This is a routing-first **partial** map for stock page `0`. It retains every
native Detour component selected by an exact world handoff or supported NM
source position. It does not invent connections across Attohwa's mountain
climb, geysers, drops, or zone thresholds.

The retained graph is useful for ordinary walking on both large terrain
networks and for the small native threshold fragments. Completion still
requires attended page calibration and live review of Parradamo Tor, one-way
traversal, the Boneyard Gully and Maze of Shakhrami thresholds, and recovery
behavior near disconnected terrain.

## Stock calibration

The imported stock catalog has one page, page `0`, which is also the default.
Use `stock_calibration = true`; no scale, origin, mask, elevation band, page
transition, structure image, or manual graph transition is authored here.
