# Alzadaal Undersea Ruins (zone 72)

## Status and sources

This is a routing-first **partial** map. It retains fourteen independently
proved native Detour components selected by exact arrivals, zone-script porter
regions, fallback arrivals, named encounters, and Runic Portal references. It
does not invent links through Gilded Doors, Gilded Gateways, porter events,
Runic Portals, mission triggers, elevators, teleporters, drops, or nearby
navmesh fragments.

The stock catalog contains pages `1` through `12`, with page `1` as the
default. Use `stock_calibration = true`; the graph is zone-owned. Zone-script
comments explicitly assign the twenty-two porter trigger regions to stock
pages, proving page membership for thirteen substantive components. The
four-node ordinary fallback platform has no source page assignment and remains
unassigned. Sources are xiNavmeshes commit
`d5de48de84868bde744e4864768a611e5aad82b0`, CatsEyeXI commit
`314deaf03465f2b24b6a1e4e73a016ca036f1084`, and
`assets/world/connections.lua`. `Alzadaal_Undersea_Ruins.nav` SHA-256 is
`08005622BBDD4E4C923E774FC6583F077D3704D3D7B2FE92C971F020E351DE47`.
CatsEye SQL/script `(x, vertical, z)` becomes live `(x, y=z, z=vertical)`.
