# Misareaux Coast (zone 25)

## Status

This is a routing-first **partial** map. It retains seven native regions
selected by exact zone thresholds, travel points, gates, and supported NMs.
One attended, one-way descent connects the lower-Safehold network to the
eastern Dilapidated Gate shelf. The graph does not invent links across mission
gates, event teleports, other cliffs, remote shorelines, or native seams.

The stock catalog has one page (`0`), which is also the default. The graph is
zone-owned (`page_id = nil`); no page rule is necessary.
