# Fort Ghelsba (zone 141)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact world handoff, the active Survival Guide, all five active
Treasure Chest possibilities, and the three supported fixed-NM references. It
requires no structure image and authors no transition or blocked-link
exception.

The supported destinations select four disconnected native components. Fort
Ghelsba contains an elevator with distinct lower and upper doors as well as
raised fort platforms. The pinned NPC records prove that the elevator exists,
but they do not provide attended entrance, midpoint, and exit route samples.
No elevator or platform connection is inferred from projected X/Y proximity.

## Stock calibration

The imported stock catalog has one page, page `0`. Runtime
`stock_calibration = true` is authoritative for the exact FFXiMain map-table
scale and origin. This session did not have a pinned static capture of the
numeric page-0 record, so its scale byte and offsets remain a provenance
blocker rather than being guessed.
