# Vunkerl Inlet [S] (zone 83)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact physical handoff, the Survival Guide, the fixed Treasure
Coffer cluster, four supported active static NMs, and substantial components
backed by ordinary non-campaign mob records. No transition, one-way
transition, or blocked-link exception is authored.

The stock catalog has only page `0` and defaults to page `0`. The graph is
zone-owned; no page rule or page graph seed is required. Catalog integration
should retain live stock calibration.
