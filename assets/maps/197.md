# Crawler's Nest (zone 197)

## Status

This is a routing-first **partial** map. It publishes only native Detour
topology selected by exact world handoffs and supported CatsEyeXI destinations;
it does not invent links across doors, drops, ramps, floors, or navmesh seams.
No structure image is required.

The notorious-monster layer is complete for the pinned server revision: nine
distinct supported NMs are represented by ten page-scoped records and 109
exact possible positions. Stock pages `14`, `15`, and `16` correspond to Maps
1, 2, and 3. Page `17` is Map 4 and contains no supported NM. Cross-component
destinations remain marker-only.

Completion still requires attended traversal of route-affecting seams, live
reload and route/recovery checks, classification of the excluded native
components, and exact numeric stock-page calibration.
