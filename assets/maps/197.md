# Crawler's Nest (zone 197)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both exact Rolanberry Fields handoffs, the Survival Guide, every pinned
active chest and coffer possibility, and conservative nonzero initial-spawn NM
records without requiring or generating a structure image. No transition or
blocked-link exception is authored.

The supported destinations occupy four separate native components. The
southern entrance and Survival Guide form a small entrance pocket; the western
entrance reaches the northern chest network; the northern coffer/NM network is
separate; and the southern chest/Dynast Beetle network is separate. No stair,
drop, tunnel, ramp, door, or floor handoff is inferred from proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
