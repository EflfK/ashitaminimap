# Ru'Lude Gardens map provenance

- Zone: Ru'Lude Gardens (`243`)
- Vanilla DAT: `<FFXI>/ROM/18/75.DAT` (`m_243_00`)
- Source page: 512 × 512, cyclic horizontal offset `+146 px`
- Collision/navigation: `RuLude_Gardens.obj` and `RuLude_Gardens.nav`
- Walkable seeds: main `(0, 0)`; east stairs
  `(51.480, -32.704)` and `(49.5, -41.5)`; upper
  `(44.204, -68.997)`
- Calibration: origin and H-8 grid center `(255, 256)`, `0.80 px/yalm`,
  `40 yalms/cell`
- View bounds: complete `(0,0)-(512,512)` page

The first Detour component covers the main garden level. The second seed is a
live-verified walkable position at elevation `10` on the embassy approach; it
retains the overlapping upper-level paths that a two-dimensional `(0, 0)` seed
cannot select. Each component is rendered to a separate runtime layer so both
retain their boundary outlines where they cross in the flattened map. The
disconnected upper component uses a violet edge/fill treatment while the main
connected network remains cyan. The remaining disconnected collision surfaces,
including the large inaccessible rectangle east of the playable garden, stay
excluded.

The east staircase is split into two isolated Detour polygons by navmesh gaps.
The first seed is the live-verified player position at elevation `3.0`; the
second selects the aligned uphill stair flight at elevation `6.2`. They are
rendered violet with the upper component. The display-path graph adds three
authored bidirectional links along this staircase only, joining the lower
network, both stair fragments, and the upper network. A fourth authored link
joins the verified central-west staircase landings near `X 0`, allowing the
router to select that shorter climb when appropriate. These links permit
truthful floor transitions without connecting unrelated overlapping surfaces.
The generated graph also removes the source-navmesh adjacency between the
upper polygons centered near `(3.962, -63.008)` and `(3.962, -67.008)`;
live verification confirmed that the apparent passage is physically blocked.

## Runtime floor selection

The main garden layer is the lower logical floor and matches player Z values
through `2.9`. Both disconnected stair fragments are part of the violet route
to the upper floor, so the stairs and upper structure share the player-Z band
starting at `3.0`. This boundary comes directly from the recorded live position
on the first east stair; the upper component's recorded live elevation is
`10.0`.

The shared upper-route band is intentional: the stairs are connectors, not a
third floor. When the player is below the first stair, both violet textures use
**Other floors opacity**. From the first stair upward, the cyan main garden
uses **Other floors opacity** and both violet textures use **Current floor
opacity**.
