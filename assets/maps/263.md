# Yorcia Weald (zone 263)

## Status

This is a routing-first **partial** map. It publishes the single native
Detour component selected by the exact physical handoffs, the server default
arrival, all active fixed travel destinations, and named fixed mechanism and
quest records. No mask, elevation filter, transition, one-way transition, or
blocked link is authored.

The result intentionally does not claim complete outdoor coverage. The source
navmesh is heavily fragmented, and the exact Pellucid Afflusion coordinate is
not safe as a generator selector because it lies over a stacked 13-node
fragment. Runtime floor-aware snapping still resolves that destination on the
retained component; it is validation-only and does not select topology.

## Component review

The unseeded native graph has 22,492 nodes, 21,950 bidirectional connections,
2,210 components, and 1,094 isolated nodes. Its largest component has 6,890
nodes. The unseeded inferred graph is byte-identical; geometric inference
does not repair the source fragmentation.

Every retained selector resolves to the 6,890-node component. The other
15,602 nodes in 2,209 components are excluded. The largest omitted fragments
have 995, 713, 693, 535, 442, 379, 330, 305, and 279 nodes. No omitted
component is promoted from size, visual proximity, an anonymous collision
record, or a map-grid label alone.

The production graph has 6,890 nodes, 7,822 bidirectional connections, one
component, and no isolated nodes. The focused auditor reports no steep edges,
stacked-floor overlaps, or nearby-component advisories. It retains three
native long edges:
