# West Ronfaure (zone 100)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for the main outdoor surface and three destination-affecting threshold
components. It requires no structure image and authors no transition or
blocked-link exception.

Four source seams block a completion claim:

- the 10-node Ghelsba threshold does not join the main outdoor component;
- the 38-node northern Fort Ghelsba threshold does not join the main outdoor
  component;
- the 17-node Bostaunieux threshold and Marauder Dvogzog component does not
  join the main outdoor component; and
- the exact outbound La Theine and East Ronfaure handoff records do not snap
  within the runtime 24-yalm radius, although their paired arrival records
  reach the main component.

The three nearby-component leads need focused attended
entrance/midpoint/exit captures before any `--transition` can be authored.
AshitaMCP was unavailable during this audit, so off-route recovery and live
calibration could not be tested.

## Stock calibration

The imported stock catalog identifies one page, `m_100_00`. Runtime stock
calibration should remain authoritative via `stock_calibration = true`.
The installed `FFXiMain.dll` did not expose the expected static table
signature and the live addon bridge was unavailable, so the exact scale byte
and signed offsets remain unresolved. This blocks a claim of exact calibrated
completion but does not change graph world coordinates.
