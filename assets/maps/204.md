# Fei'Yin (zone 204)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both Home Points, all active fixed Treasure Chest possibilities, every
active locatable NM and quest encounter in the pinned CatsEyeXI source, and
all five verified physical handoffs. No transition or blocked-link exception
is authored.

The stock catalog contains pages `1`, `14`, and `15`, with page `1` as the
default. Exact numeric calibration is now recorded below. Page `14` is blank
parchment; pages `1` and `15` are the two detail floors. The main retained
graph component spans both floors, so component-owned page selection would be
false. Exact automatic switching between pages `1` and `15` remains a live
verification blocker; the graph therefore remains zone-wide and stock runtime
page selection remains authoritative.

| `14` | 2 | `(-256,-272)` | `(256,272)` | `0.40 px/yalm` | `80 yalms` |
| `15` | 2 | `(-256,-272)` | `(256,272)` | `0.40 px/yalm` | `80 yalms` |

different floor artwork. This proves calibration, but not the precise runtime
page-switch boundary; no elevation rule is guessed from artwork.
