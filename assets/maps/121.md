# The Sanctuary of Zi'Tah (zone 121)

## Status

This is a routing-first **partial** map. The graph retains only native Detour
components selected by exact world handoffs and supported CatsEyeXI
destinations. No shelf, boundary seam, threshold gap, or encounter boundary is
bridged.

The ordinary NM layer is complete for the pinned server revision: nine active
supported NMs and 32 exact trigger or possible spawn positions. The zone has
one stock image, page `0`, and every supported NM is assigned to that surface.

Completion still requires attended review of the Hall of the Gods threshold
and excluded terrain fragments, exact numeric stock calibration, and a live
addon reload with route/recovery checks. Cross-component destinations remain
marker-only.

## Deterministic selection

The selector keeps the ten exact handoff endpoints, Survival Guide, and one
representative point for every selected native surface. Updating the NM audit
only replaces stale initial-row selectors with truthful trigger/script points
and removes ten unimplemented Elite Training selectors. Guardian Treant's
trigger already floor-aware snaps 15.164 yalms to the retained surface, so a
selector that would add an unnecessary 27-node fragment is deliberately not
used.

The resulting graph is byte-identical to production: no native component,
edge, transition, or path artifact changes are required.
