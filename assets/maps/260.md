# Yahse Hunting Grounds (zone 260)

## Status

This is a routing-first **partial** map. It publishes the single native
Detour component selected by exact physical handoffs, the server default
arrival, all four active Waypoints, and fixed quest/mechanism records. No
mask, elevation filter, transition, one-way transition, or blocked link is
authored.

The result intentionally does not claim complete outdoor coverage. The full
source graph is extremely fragmented, one exact Ra'Kaznar arrival has no
nearby graph surface, and the eastern Castoff Point cannot be selected from
its exact coordinate without choosing the wrong stacked polygon.

The server default arrival is `(361.000,-211.000,4.000)`. The four active

The map-owned travel schema currently accepts only Home Points and Survival

Waypoint coordinates are graph selectors and validation destinations rather
than `travel_references` entries.

The following exact active fixed records also select or validate the main

The eastern Castoff Point is exactly `(419.316,-14.522,1.365)`. A truthful
same-floor polygon exists about 3.151 yalms away in the full graph, but the
exact XY coordinate lies inside an unrelated stacked polygon around live Z
`10`. The generator therefore selects that wrong 11-node surface before it
considers the nearby same-floor centroid. No adjusted or derived selector is
substituted. The eastern endpoint and any castoff/drop behavior remain
attended-only, with no authored transport edge.

There are no active fixed Treasure Chest or Treasure Coffer records. The
pinned mob sources contain ordinary field mobs, Reive groups, and special or
event records such as Startled Uragnite and Bothersome Chapuli, but no pinned
standard NM lifecycle/placeholder evidence sufficient for an honest
`nm_spawn_ranges` record. Treasure and NM catalogs are therefore empty.

## Component review

The unseeded native graph has 23,022 nodes, 23,047 connections, and 1,553
components. Its largest component has 2,810 nodes. The unseeded inferred graph
has the same nodes and 23,051 connections, only four more edges; inference
does not repair the source fragmentation.

Every retained exact destination above resolves to the 2,810-node component.
The other 20,212 nodes in 1,552 components are excluded. They include large
fragments of 1,303, 1,244, 697, 654, 645, 599, 553, and 512 nodes as well as
many tiny pieces. No excluded component is promoted from size, visual
proximity, or a map-grid label alone.

The production graph has 2,810 nodes, 2,987 bidirectional connections, one
component, and no isolated nodes. The focused auditor reports no steep edges,
stacked-floor overlaps, or nearby-component advisories. It retains three
native long edges:

```text
(424.100,357.100) to (422.875,330.250): 26.878 yalms
(295.125,229.750) to (294.300,202.900): 26.863 yalms
(325.200,-12.400) to (357.667,-11.750): 32.543 yalms
```

These are source-native connections, not authored transitions.
