# Beaucedine Glacier (zone 111)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both Beaucedine-side points of every exact physical handoff, the active
Survival Guide and Treasure Coffer, and five conservative nonzero
initial-spawn NM records without requiring or generating a structure image.
No transition or blocked-link exception is authored.

The main outdoor surface and its supported destinations occupy one large
native component. Each of the six Pso'Xja handoffs also retains a small
arrival/departure ledge and a separate one-node threshold. Source geometry
alone does not prove the drops, ramps, or zoning mechanisms between those
pieces, so they are not joined from proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
