# Ifrit's Cauldron (zone 205)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every verified physical handoff, the Home Point, Survival Guide, all 13
active fixed Treasure Coffer possibilities, four timed Flame Spouts, and every
supported NM start. No transition, blocked-link, or page-ownership exception
is authored.

The imported stock catalog contains pages `1`, `2`, `3`, `4`, `5`, `15`,
`16`, `17`, and `18`, with page `1` as the default. The zone has many stacked
floors, drops, lava passages, and timed barriers. No deterministic source in
this audit assigns the retained components to those stock pages, so the graph
is zone-wide and stock runtime page selection remains authoritative.
