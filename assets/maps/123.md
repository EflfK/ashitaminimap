# Yuhtunga Jungle (zone 123)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact physical handoff, the Survival Guide, and pinned nonzero
initial-spawn NM records without requiring or generating a structure image.
No transition or blocked-link exception is authored.

The source mesh divides the supported destinations among seven native
components. Only the Norg, Survival Guide, central Yhoator thresholds,
Koropokkur, and Pyuu component provides a broad continuous route network.
The Sea Serpent Grotto/Meww, northern Yhoator, Ifrit's Cauldron, Rose
Garden/Bayawak, Mischievous Micholas, and southern Yhoator components remain
separate pending attended entrance/midpoint/exit evidence. No cliff, tunnel,
root bridge, ledge, or zone seam is inferred from proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
