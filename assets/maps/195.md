# The Eldieme Necropolis (zone 195)

## Status

This is a routing-first partial map with an exhaustive catalog of active,
locatable named encounters in the pinned CatsEyeXI source. The graph publishes
only native Detour topology for components containing a verified world handoff,
supported destination, or active encounter. It does not invent links across
Eldieme's gates, drops, stairs, or navmesh seams.

The remaining routing work requires attended captures for route-affecting gates
and one-way drops, classification of the unselected native components, and a
live addon reload with route/recovery/page-filter checks. Destinations on
different native components therefore remain marker-only.

## Explicit exclusions

- `Lich C Magnus` (level 58) has SQL and a mob script but no active controller
  or NPC trigger in the pinned source. The rotating `qm1` is initialized for
  Acting in Good Faith but has no zone NPC script that spawns the mob.
- `Namorodo` (level 61-65) has three SQL rows and `qm2`, but no mob script or
  active spawn controller; two rows are zero placeholders.
- `Gasha` (level 94-95) belongs to the three Planar Rift Voidwatch encounter
  and is excluded from ordinary/quest NM overlays.
- `Mimic` is treasure-container behavior, and the Strange Apparatus Ice
  Elemental is apparatus failure behavior; neither is an NM-layer target.
- `Marchosias` is an ordinary respawning mob group, not an NM.

These exclusions prevent dormant SQL rows, event infrastructure, and ordinary
mobs from appearing as actionable NM markers.
