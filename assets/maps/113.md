# Cape Teriggan (zone 113)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for every exact physical handoff, the Home Point, the Survival Guide, and the
supported static NM possibilities listed below. It does not require or create
a structure image, and it authors no transition, one-way transition, or
blocked-link exception.

The retained graph has six disconnected native components. Each contains an
exact supported destination. They remain disconnected because unattended
source evidence does not prove a player connection between them. Completion
still requires focused live review of the main/east component lead, native
long edges, zone thresholds, route recovery, and stock-page behavior.
