# Ru'Aun Gardens (zone 130)

## Status

This is a routing-first **partial** map. It retains every native Detour
component selected by an exact zone handoff, active travel point, active
Treasure Coffer possibility, relevant fixed/lottery NM record, or one pinned
nonzero active-mob control per otherwise unrepresented source component. No
transition, one-way transition, or blocked edge is invented.

The imported stock catalog has pages `1` through `18`, defaulting to page `1`.
Exact page calibration remains available from the stock records at runtime,
but deterministic page ownership for the retained components is not present
in the pinned sources. The graph therefore remains zone-owned with
`page_id = nil`; no component is assigned to a stock page by visual inference.
