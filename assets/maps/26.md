# Tavnazian Safehold (zone 26)

## Status

This is a routing-first **partial** three-page map. It publishes all active
Home Points and the Survival Guide on their stock pages, and retains the
native navigation components supported by those destinations, physical zone
thresholds, and representative public NPCs. It does not invent vertical links
across disconnected Safehold annexes.

The stock catalog has pages `1`, `2`, and `3`. Live Ashita page selection is
used; the user's page-2 screenshot independently confirms the Home Point #1
floor. The page associations are also listed by the BG-Wiki Tavnazian
Safehold map table:
`https://www.bg-wiki.com/ffxi/Tavnazian_Safehold`.

CatsEyeXI SQL tuples are `(x, vertical, z)`. Minimap records use live
`(x, y, z)`, so source `z` becomes world Y and source `y` becomes live Z.
Generated graph Z is the negation of live Z.

## Native component selection

The unseeded native graph has 1,088 nodes, 1,094 bidirectional edges, and 37
components, including 24 isolated nodes. Three page-owned artifacts retain
only components selected by exact source-backed points:

| Page | Nodes | Edges | Components | Exact selectors |
| ---: | ---: | ---: | ---: | --- |
| 1 | 864 | 897 | 814 + 50 | Home Point #3; Yurim |
| 2 | 867 | 899 | 814 + 53 | Home Point #1; Travonce |
| 3 | 95 | 100 | 95 | Home Point #2 |

The 814-node central/ramp component is retained on pages 1 and 2 because the
source navmesh physically connects the areas represented by both stock pages.
The runtime still changes the visible stock page from live Ashita state.

The page-1 annex is 2.039 yalms away in plan view but 10.700 yalms apart in
elevation. The page-2 annex is 2.125 yalms away in plan view but 10.600 yalms
apart in elevation. These are audit leads, not proof of walkable transitions;
both remain disconnected until attended entrance/midpoint/exit evidence is
available. Page 3 is a single connected component.

## Boundaries and representative routes

The central component contains the exact Lufaise Meadows and Misareaux Coast
arrivals, Home Points #1 and #3, the Survival Guide, and most public NPCs. The
page-3 component contains Home Point #2, the Sewer Entrance, and the physical
thresholds to Phomiuna Aqueducts and Sealion's Den.

Representative route checks:


Yurim and Travonce snap to their supported annex components at 1.130 and
1.074 yalms, but routes from the central component are deliberately not
claimed. Zoning itself is not represented as a graph edge.

## Treasure and NMs

There is no active fixed Treasure Chest or Treasure Coffer in the pinned
Safehold records, so `treasure_spawns` is empty. The pinned mob-group source
has no active Tavnazian Safehold group, so there is no supported NM spawn
range to publish.
