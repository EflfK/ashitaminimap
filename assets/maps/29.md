# Riverne - Site B01 (zone 29)

## Status

This is a routing-first **partial** map. It retains all 17 substantial native
islands selected by exact spatial-displacement, unstable-displacement, arrival,
travel, monument, and supported NM evidence. It does not invent links across
spatial displacements, Giant Scale portals, battlefield events, drops, or
nearby navmesh islands.

The stock catalog has pages `1` and `2`, with page `1` as the default. The
graph is deliberately zone-owned (`page_id = nil`) because the pinned records
do not assign the 17 retained components to stock pages. No page rule or page
transition is published without attended page evidence.

## Spatial and unstable displacements

The pinned NPC table contains the exact island-side positions of 35 ordinary
Spatial Displacements, three named `_0t1`-`_0t3` Unstable Displacements, the
separate unstable battlefield approach, and the battlefield exit. Their
source order selects all 17 production components.

Spatial Displacement events are selected from NPC-ID offsets. Only two event
destinations are explicit in scripts: event 33 enters Monarch Linn at
`(12.527,-539.602,0.345)` in zone 31, while event 10 returns to Misareaux
Coast at `(-538.526,359.219,-29.5)`. Other internal destinations are encoded
inside cutscenes and lack exact before/after records. The `_0t1`-`_0t3`
portals also require a Giant Scale to enlarge temporarily before their events
can be used. None is represented as an ordinary edge.

The default arrival `(729.749,407.153,-20.319)` snaps at 3.169 yalms on the
same 85-node island as the first positive-Y displacement pair. The world
connection table has no zone 29 record; event scripts, not physical threshold
records, are the available evidence.

Forty-five exact SQL destinations plus the arrival and three NM samples snap
within 0.523-11.407 yalms. Fifteen representative same-island routes pass,
ranging from 0.000 to 159.796 graph yalms. These routes validate island
topology only and do not assert a displacement, drop, or event pairing.
