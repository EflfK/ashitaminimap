# Gustav Tunnel (zone 212)

## Status

This is a routing-first **partial** map. It publishes native Detour topology
for both sides of each exact world handoff, the active Survival Guide, and all
active ordinary or quest/mission-triggered NM locations without requiring or
generating a structure image. No transition or blocked-link exception is
authored.

The supported destinations occupy nine native components. Source geometry
alone does not prove how the tunnel's ledges, drops, ramps, or stacked regions
connect, so no cross-component link is inferred from proximity.

The exact page-0 map-table record was not captured in this session. Runtime
stock calibration remains authoritative through `stock_calibration = true`,
but numeric scale and offsets must be recorded before the map can be described
as fully calibrated.
