# Crawler's Nest [S] (zone 171)

## Status

This is a routing-first **partial** map. It publishes four independently
supported native Detour components selected by exact physical boundaries,
the zone fallback, the Survival Guide, stable notorious-monster records, and
ordinary non-campaign spawn coverage. No campaign, door, gate, trap,
transport, drop, transition, one-way transition, or blocked-link exception is
authored.

The imported stock catalog contains pages `0` through `3`, with page `0` as
the default. The graph remains zone-owned (`page_id = nil`) pending attended
stock calibration and proof of component-to-page membership. Shared
integration should use `stock_calibration = true` and no page rule.
