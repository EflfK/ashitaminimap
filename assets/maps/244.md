# Upper Jeuno map provenance

- Zone: Upper Jeuno (`244`)
- Vanilla DAT: `<FFXI>/ROM/18/76.DAT` (`m_244_00`)
- Source page: 512 × 512, cyclic horizontal offset `+146 px`
- Collision/navigation: `Upper_Jeuno.obj` and `Upper_Jeuno.nav`
- Walkable seeds: `(0, 0)` and `(-57, 89.5)`
- Calibration: navigation origin `(272, 304)` from signed FFXiMain page-record
  offsets `(-272, -304)`; H-8 grid center `(255, 256)`; `0.80 px/yalm`,
  `40 yalms/cell`
- View bounds: complete `(0,0)-(512,512)` page

The first Detour component retains the main street network. The second seed is
on the Chocobo Stables floor near Brutus's verified position
`(-57.023, 97.519)` and retains that overlapping lower-area structure. The
components are rendered separately so neither loses its boundary outline where
their projections overlap. The disconnected Stables component uses violet
fill and edges while the main street network remains cyan. The other
disconnected components remain rejected, including roofs, the residential-area
collision circle, and off-map islands.

```text
python tools/generate_vanilla_layer.py <DAT> assets/maps/244_vanilla.png \
  --x-offset 146 --box 0,0,512,512
python tools/generate_walkable_map.py <OBJ> <NAV> \
  assets/maps/244_structure.png --origin-x 272 --origin-y 304 \
  --pixels-per-yalm 0.8 --seed 0,0
python tools/generate_walkable_map.py <OBJ> <NAV> \
  assets/maps/244_stables_structure.png --origin-x 272 --origin-y 304 \
  --pixels-per-yalm 0.8 --seed=-57,89.5 \
  --fill-rgb 42,30,66 --edge-rgb 181,132,255
```

The structure must be regenerated whenever the navigation origin changes.
Moving only the runtime marker transform leaves the cyan walkable geometry
misregistered against both the vanilla page and live entities.
