# Promyvion-Mea (zone 20)

## Status

This is a routing-first **partial** map. It retains the five substantial native
components selected by exact evidence for floors 1, 2, 3-west, 3-east, and 4.
It does not invent links across Memory Stream portals, optional-cutscene floor
returns, the Hall of Transference exit, the Spire of Mea boundary, drops, or
native component seams.

The stock catalog has one page (`0`), which is also the default. The graph is
zone-owned (`page_id = nil`); no page rule or transition is necessary.
