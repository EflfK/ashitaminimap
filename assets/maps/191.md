# Dangruf Wadi (zone 191)

## Status

This is a routing-first **partial** map. It publishes conservative native
Detour topology for both exact world handoffs, the active Survival Guide, all
15 active Treasure Chest possibilities, and both supportable active NMs with
their complete pinned spawn behavior. It requires no structure image. One
live-verified geyser pad seam and one attended one-way geyser transition are
authored; there is no blocked-link exception.

The destinations originally selected four disconnected native components.
Dangruf Wadi uses geysers to move between elevations, and the pinned navigation
source does not prove those player transitions. One reported geyser now joins
the southern and central/northern networks through its six-polygon pad. No
other component is joined from projected X/Y proximity. Each remaining geyser
connection requires focused attended evidence before a transition can be
authored.

## Stock pages and calibration

The imported stock catalog contains pages `0`, `1`, and `14`, with page `0`
as its default. Runtime stock calibration remains authoritative for each
page's exact FFXiMain scale and origin.

This session did not have pinned numeric map-table records, page-specific
world footprints, or live page/elevation samples. The graph is therefore
page-independent (`page_id = nil`) and preserves its disconnected elevations,
but page ownership and page-switch rules remain unresolved. The map must not
be described as page-complete until each retained component is assigned to its
truthful stock page from deterministic records and live controls.

## Live-verified geyser transition

The attended screenshots captured the player at the geyser start and its
one-way landing, in traversal order:

```text
start: (-132.8, 130.9, 3.6)
end:   (-137.0, 137.5, 0.0)
```

Live Z is inverted, so the more-negative destination elevation is physically
higher. The Detour graph resolves the start to the six-node geyser-pad node
`(-132.600,130.900,3.174 live Z)` and the landing to
`(-136.167,139.167,-0.480 live Z)`. The pad's nearest lower-floor node is
`(-131.375,128.625,3.854 live Z)`, 2.584 yalms away in X/Y with 0.680 yalm of
elevation difference. The first screenshot proves the pad is physically
reachable from that surrounding floor, so the narrow source seam is joined
bidirectionally. The geyser edge itself is one-way from the pad to the higher
landing and carries the attended route instruction `Stand on the geyser.` No
reverse edge is authored.

The four seeds plus the attended exceptions retain the same destination-bearing
networks and add only the six-node geyser pad. No page ID, mask, elevation

components cannot yet be assigned truthfully among stock pages `0`, `1`, and
`14`.
