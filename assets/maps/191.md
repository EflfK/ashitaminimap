# Dangruf Wadi (zone 191)

## Status

This is a routing-first **partial** map. It publishes conservative native
Detour topology for both exact world handoffs, the active Survival Guide, all
15 active Treasure Chest possibilities, and the two supported fixed-NM
references. It requires no structure image and authors no transition or
blocked-link exception.

The destinations select four disconnected native components. Dangruf Wadi
uses geysers to move between elevations, and the pinned navigation source does
not prove those player transitions. No component is joined from projected X/Y
proximity. Each missing geyser connection requires attended entrance,
midpoint, and exit evidence before a `--transition` can be authored.

## Stock pages and calibration

The imported stock catalog contains pages `0`, `1`, and `14`, with page `0`
as its default. Runtime stock calibration remains authoritative for each
page's exact FFXiMain scale and origin.

This session did not have pinned numeric map-table records, page-specific
world footprints, or live page/elevation samples. The graph is therefore
page-independent (`page_id = nil`) and preserves its disconnected elevations,
but page ownership and page-switch rules remain unresolved. The map must not
be described as page-complete until each retained component is assigned to its
truthful stock page from deterministic records and live controls.
