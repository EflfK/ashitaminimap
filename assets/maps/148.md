# Qulun Dome (zone 148)

## Status

This is a routing-first **partial** map. It retains native Detour components
selected by all six exact Beadeaux handoff sides, both mission doors, the
Magicite and Limit Break 3 destinations, and the supported Diamond Quadav and
Za'Dha Adamantking references. It does not invent links across doors, mission
state, navmesh seams, or the unsupported Hu'Rhe reference.

The stock catalog has one page (`0`), which is also the default. The graph is
zone-owned with `page_id = nil`; no page rule or transition is necessary.
