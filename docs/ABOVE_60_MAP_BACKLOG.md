# Above-level-60 production-map queue

This queue continues the routing-first campaign after
`LEVEL_60_MAP_BACKLOG.md`. It covers ordinary combat and travel zones whose
material use extends beyond level 60. It retains the earlier scope exclusions:
cities and residential areas, ships and airships, battlefields and instanced
event areas, Dynamis, Abyssea, and non-playable or private zones.

The tiers are authoring priorities rather than claims that every monster in a
zone falls inside one level band. Work proceeds with one map owner per zone and
no more than three concurrent map audits. A map remains partial whenever
truthful completion requires attended traversal, live page evidence, or a
verified exception edge.
